# 禁閉逃殺：文字獄

《禁閉逃殺》的文字冒險／抽卡衍生作。單一 `index.html`，直接用瀏覽器開啟即可（支援 file://）。

- **招募所**：花金條抽職業卡（SSR 3%／SR 17%／R 80%，十連保底 SR、60 抽保底 SSR），重複卡升星。
- **逃殺遠征**：從 B7 停屍間爬到 2F 停機坪。選房間、搜物資、躲毒氣；遇到其他逃殺者可結盟、交易、突襲或避開，盟友信任太低會背叛。直升機只有三個座位。
  - 主線 12 章：禁閉室 → 地下研究所 → 孤島監獄 → 黑塔 → 深海方舟 → 天空審判所 → 輪迴之獄 → 原點 → 觀眾席 → 終局 → 選角室 → 冠軍之戰（第 9～12 章偏難），通關一章解鎖下一章，敵人更強、獎勵更多，首通有額外金條，打倒魔王必掉一件裝備。
  - 🕳 無盡深淵（通關第 1 章解鎖）：沒有終點，每 5 層一個守門者，打倒後可選擇撤離或繼續往下，紀錄最深層數。
  - 遠征會自動存檔，中途關掉網頁，下次打開會接著玩。
- **熔煉**：選 2 名同稀有度角色（整張卡），熔成 1 名同稀有度的其他角色，優先給還沒擁有的。新角色的等級、星數、突破都取兩者較低的；熔出已擁有的角色時，各項保留較高的那邊。隊伍中、遠征中的角色不能熔煉。
- **難度**：主線每章可選 🟢簡單／🟡普通／🔴困難。普通：敵人生命、攻擊、防禦、速度 ×2，金條、突破石、章節魔王掉落的裝備 ×2；困難全部 ×3。無盡深淵不分難度。
- **防作弊**：存檔與匯出代碼都有簽章；簽章不符（存檔在遊戲外被改過）或出現遊戲規則不可能的數值（星數、等級、突破、強化、詞條、金條等），存檔會被清空。純網頁遊戲無法 100% 防作弊，這是擋掉直接改存檔的做法。
- **卡住了／回報問題**：遊戲會自動記錄錯誤與重要事件（最近 300 筆）。畫面右下角永遠有一顆「🆘」按鈕（頁尾、遠征側欄、戰鬥上方也有 🐞），可以重置這一層（回到選房間前）、強制結束戰鬥、強制回到主頁（遠征進度保留）、離開網路對戰房間、重新整理，或複製紀錄回報給開發者。手機連點兩下不會重複觸發，畫面出錯時也會顯示自救按鈕。
- **魔王討伐（支線）**：通關第 1 章後開放，8 位強度偏高、可以不打的魔王（滅世獵手、虛空主宰、命運裁決者、死神代行者、深淵君王、永夜帝王、天命霸主、終焉行者），依序解鎖，各有個人故事。打倒第一條命後會爆氣進入第二階段（換圖、回血、變強）。打贏有機會掉落魔王專屬 EX 裝備（首次討伐必掉、之後 2%）。
- **轉移**：隊伍頁「🔁 轉移」可以把一名角色的等級（連同經驗值）轉給另一名「等級比較低」的角色：目標變成來源原本的等級，來源回到 Lv.1。費用 🪙 = 轉移的等級 × 3。星數、突破、裝備不會轉移；來源降級後，身上等級要求不足的裝備會暫時失效。遠征中的角色不能轉移。
- **職業**：每個角色屬於一種職業——🛡坦克（生命+15%、防禦+1）、⚔戰士（攻擊+15%）、🗡刺客（速度+1、暴擊+6%）、🎯射手（暴擊+12%）、✚輔助（治療+30%）、🔮術士（技能傷害+20%、中毒+1）。隊伍頁可以依職業篩選。
- **裝備稀有度與詞條**：N 普通／R 稀有／SR 精良／SSR 史詩／UR 傳說。精良要角色 Lv.5、史詩 Lv.10、傳說 Lv.15 才能穿。每件裝備的數值有品質浮動，並依稀有度帶 0～3 條隨機詞條（攻擊、生命、防禦、速度、暴擊、吸血、閃避）。同稀有度的武器／防具／飾品穿 2、3 件有套裝效果。
- **裝備／強化**：角色有武器、防具、飾品三個欄位（武器有職業限制）。裝備可強化到 +10，每級基礎數值 +8%；+1～+4 失敗無損失，+5～+10 失敗掉 1 級，裝備不會碎。🧿保護符防掉級、🍀幸運符成功率 +10%。不要的裝備可以分解換金條。
- **角色裝備調整區**：「裝備」頁上方切換到「🧍 角色裝備調整」，選角色、選裝備欄，倉庫裡的裝備會列出來，點一件就能預覽穿上之後的生命、攻擊、防禦、速度、暴擊、吸血、閃避（含套裝加成，綠色變強、紅色變弱），確認再穿上。
- **裝備圖鑑**：「裝備」頁切換到「📖 裝備圖鑑」，35 件裝備全部展示（沒拿過的顯示成暗色），可依稀有度篩選；點開看基礎與強化後數值、品質浮動範圍、可能的隨機詞條、套裝效果和取得方式，並列出各稀有度的套裝加成。
- **裝備排序**：倉庫和角色裝備調整區可以依「強度／稀有度／強化等級／最新獲得」排序，再按一次同一個按鈕切換由高到低或由低到高；每件裝備都顯示強度分數（攻擊、防禦×3，速度×2.5，暴擊、閃避×1.5，生命×0.5，吸血×1），選擇會記在這台裝置上。
- **商店**：用金條買裝備（R／SR 直購、裝備箱抽 SSR）、強化符，以及遠征物資（放進行囊，下一次遠征自動帶上）。
- **遣散／合成**：不要的角色可以遣散換金條（R 🪙3／SR 🪙10／SSR 🪙30，每星計算），或投入 6★ 份的 R 合成 1 名隨機 SR、6★ 份的 SR 合成 1 名隨機 SSR。合成視窗有「⚡ 一鍵合成」，自動挑等級低、星數少的角色當材料，能合幾次就合幾次（不會動到隊伍中、遠征中、已突破的角色）。
- **存檔**：自動存在瀏覽器；主頁可「匯出／匯入存檔」，用代碼把進度搬到別的裝置。
- **突破**：角色 5★ 後可以消耗 💎突破石 突破，成功率從 30% 起每次 ×0.85 遞減（30→26→22→…→7%）。成功：星星回到 1★ 重新累積，原本的能力全部保留，另外全能力 +1.5%，突破後每升 1 星 +2.5%；失敗：突破石消失、不會降星。第 n 次突破需要 2n 顆突破石，最多 10 次。突破石來源：商店（🪙15）、5★ 後抽到重複卡、主線魔王、深淵守門者、練功房、成就。操作：隊伍頁點角色 →「✨ 突破」。已突破的角色不會被一鍵合成當材料。
- **碎片兌換**：5★ 後重複抽到角色（R+1／SR+3／SSR+10）、遣散 SR／SSR（每星 SR+1／SSR+3）會得到對應稀有度的 🧩碎片。招募頁「兌換角色」：沒有的角色 R 25／SR 80／SSR 200 換 1★，已擁有未滿 5★ 的角色 R 8／SR 25／SSR 70 補 1★。
- **養成賽**：雙人對決 → 網路對戰可以建立「養成賽」房間，兩人各帶隊伍頁編好的角色（最多 3 名，等級、星數、突破、裝備都算）1 對 1 PK，沒有公平限制，也沒有任何獎勵。房主會把對手送來的數值壓在合理範圍內。
- **等級**：戰鬥勝利得經驗（遠征、魔王、深淵守門者、競技場、練功房），每級全能力 +2%；Lv.50 之後所需經驗 ×5、每級只 +0.8%，最高 Lv.100。倒下的角色經驗減半。
- **練功房**：30 關可無限重打的怪物關，打贏解鎖下一關，主要給經驗，少量金條、10% 掉裝備。
- **鍵盤操作**：戰鬥中輪到你時，會預先選好一隻目標（金框＋🎯），←→（或 A D）在攻擊／技能／防禦／道具之間切換，Enter／空白鍵直接出手，不用再點敵人；想換目標按 ↑（W）移到目標列再用 ←→ 換，↓（S）回到行動列，或直接按 Tab 換目標；進到選道具或選目標時 ←→ 選擇、Enter 確認、Esc／Backspace 返回。
- **競技場**：對戰 AI 小隊爬塔賺金條，勝利有機率掉裝備。
- **雙人對決**：同機兩人蛇形選角後輪流操作互毆。

## 帳號／雲端存檔

右上角 👤 可以註冊「自訂帳號＋密碼」，登入後存檔自動上傳 Firebase（`users/{uid}`），換裝置登入同一個帳號就能接著玩；不登入也能照常玩。帳號會轉成「帳號@jbts.game」當登入信箱（不寄信，忘記密碼無法重設）。登入後可在 👤 視窗按「🔑 修改密碼」，輸入舊密碼和新密碼修改。忘記密碼時，開發者（GM）可以用 `gm/` 資料夾裡的 GM 工具幫玩家重設成臨時密碼（玩家的原密碼查不到，Firebase 只存加密結果）；GM 工具需要服務帳戶金鑰，只在開發者自己的電腦上使用，詳見 `gm/說明.txt`。只能在網路版使用。

啟用步驟（只要做一次）：
1. Firebase 主控台 → Authentication → Sign-in method → 開啟「電子郵件／密碼」。
2. 部署資料庫規則：`firebase deploy --only database`（規則在 `database.rules.json`，已加上 `users/$uid` 只能本人讀寫）。

## 劇情與老國王

12 章主線是一條連續的故事，由「老國王」（`images/npc/king.webp`）串起來：進入每一章、到魔王房之前、通關之後，他各說一段話——有的講真相（三個座位其實是王座旁的三個位子、史官寫下的最後一條規則、試煉被拿去直播……），有的提醒這一章魔王的特性。第 1～12 章的魔王也都有個人背景故事（進魔王房可以先聽）。「故事」頁會記下所有聽過的內容，通關後解鎖魔王的背景。

## 成就

「成就」頁共 28 個成就（招募、養成、遠征、戰鬥、裝備），達成時自動發金條或突破石。

## 網路對戰

雙人對決的「網路對戰」使用 Firebase Realtime Database（專案 `confinement-escape-text`）。房主的瀏覽器負責計算戰鬥，挑戰者只送出操作並接收戰況快照。資料庫規則在 `database.rules.json`，修改後用 `firebase deploy --only database` 部署。
