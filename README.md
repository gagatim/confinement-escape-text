# 禁閉逃殺：文字獄

《禁閉逃殺》的文字冒險／抽卡衍生作。單一 `index.html`，直接用瀏覽器開啟即可（支援 file://）。

- **招募所**：花金條抽職業卡（SSR 3%／SR 17%／R 80%，十連保底 SR、60 抽保底 SSR），重複卡升星。
- **逃殺遠征**：從 B7 停屍間爬到 2F 停機坪。選房間、搜物資、躲毒氣；遇到其他逃殺者可結盟、交易、突襲或避開，盟友信任太低會背叛。直升機只有三個座位。
  - 主線 6 章：禁閉室 → 地下研究所 → 孤島監獄 → 黑塔 → 深海方舟 → 天空審判所，通關一章解鎖下一章，敵人更強、獎勵更多，首通有額外金條，打倒魔王必掉一件裝備。
  - 🕳 無盡深淵（通關第 1 章解鎖）：沒有終點，每 5 層一個守門者，打倒後可選擇撤離或繼續往下，紀錄最深層數。
  - 遠征會自動存檔，中途關掉網頁，下次打開會接著玩。
- **職業**：每個角色屬於一種職業——🛡坦克（生命+15%、防禦+1）、⚔戰士（攻擊+15%）、🗡刺客（速度+1、暴擊+6%）、🎯射手（暴擊+12%）、✚輔助（治療+30%）、🔮術士（技能傷害+20%、中毒+1）。隊伍頁可以依職業篩選。
- **裝備／強化**：角色有武器、防具、飾品三個欄位（武器有職業限制）。裝備可強化到 +10，每級基礎數值 +8%；+1～+4 失敗無損失，+5～+7 失敗掉 1 級，+8～+10 失敗掉 1 級且 20% 損毀。🧿保護符防掉級／損毀、🍀幸運符成功率 +10%。不要的裝備可以分解換金條。
- **商店**：用金條買裝備（R／SR 直購、裝備箱抽 SSR）、強化符，以及遠征物資（放進行囊，下一次遠征自動帶上）。
- **遣散／合成**：不要的角色可以遣散換金條（R 🪙3／SR 🪙10／SSR 🪙30，每星計算），或投入 6★ 份的 R 合成 1 名隨機 SR、6★ 份的 SR 合成 1 名隨機 SSR。
- **存檔**：自動存在瀏覽器；主頁可「匯出／匯入存檔」，用代碼把進度搬到別的裝置。
- **突破**：角色 5★ 後可以消耗 💎突破石 突破，成功率從 60% 起每次 ×0.85 遞減（60→51→43→…→14%）。成功：星星回到 1★ 重新累積，原本的能力全部保留，另外全能力 +3%，突破後每升 1 星 +5%；失敗：突破石消失、不會降星。第 n 次突破需要 2n 顆突破石，最多 10 次。突破石來源：商店（🪙15）、5★ 後抽到重複卡、主線魔王、深淵守門者、練功房。
- **等級**：戰鬥勝利得經驗（遠征、魔王、深淵守門者、競技場、練功房），每級全能力 +2%，最高 Lv.20。倒下的角色經驗減半。
- **練功房**：30 關可無限重打的怪物關，打贏解鎖下一關，主要給經驗，少量金條、10% 掉裝備。
- **競技場**：對戰 AI 小隊爬塔賺金條，勝利有機率掉裝備。
- **雙人對決**：同機兩人蛇形選角後輪流操作互毆。

頭像 `images/avatars/*.webp` 取自本體專案。存檔存在瀏覽器 localStorage。

## 網路對戰

雙人對決的「網路對戰」使用 Firebase Realtime Database（專案 `confinement-escape-text`）。房主的瀏覽器負責計算戰鬥，挑戰者只送出操作並接收戰況快照。資料庫規則在 `database.rules.json`，修改後用 `firebase deploy --only database` 部署。
