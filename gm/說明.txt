禁閉逃殺 GM 工具　使用說明
==========================

這個工具讓你（GM）幫忘記密碼的玩家「重設」密碼。
⚠ 玩家的「原密碼」查不到：Firebase 只存加密後的結果，連你也還原不出來，
  所以做法是「幫他設一組新的」，玩家登入後再自己改掉。


一、第一次使用（只要做一次）
------------------------------
1. 下載服務帳戶金鑰（需要用建立專案的 Google 帳號登入）：
   https://console.firebase.google.com/project/confinement-escape-text/settings/serviceaccounts/adminsdk
   按「產生新的私密金鑰」→ 會下載一個 .json 檔。
2. 把這個 .json 檔直接放進這個 gm 資料夾（檔名不用改）。
3. 完成。firebase-admin 已經裝在 gm/_libs 裡了。

⚠ 這個 .json 等於你專案的最高權限：
   - 不要上傳到 GitHub（專案已設定自動忽略 gm 裡的 .json，但還是不要複製到別的地方）
   - 不要傳給任何人，不要貼到聊天室
   - 如果不小心外流，到上面那個網址刪掉這把金鑰、重新產生


二、怎麼用
----------
雙擊「GM工具.bat」，或在專案資料夾執行：
    python gm/gm.py

選單：
  1) 查詢帳號　輸入玩家帳號，會顯示註冊時間、最後登入、雲端存檔摘要
  2) 重設密碼　輸入玩家帳號，確認後產生一組臨時密碼（也可以自己指定）
  3) 列出所有帳號

也可以直接下指令：
    python gm/gm.py find 帳號
    python gm/gm.py reset 帳號            （自動產生臨時密碼）
    python gm/gm.py reset 帳號 新密碼      （自己指定，至少 6 個字）
    python gm/gm.py list


三、建議的處理流程
------------------
1. 玩家說忘記密碼 → 請他告訴你「帳號」。
2. 用「查詢帳號」看存檔摘要，問玩家「你現在大約有多少金條？幾個角色？打到第幾章？」
   對得上，才是本人（避免別人冒領別人的帳號）。
3. 用「重設密碼」產生臨時密碼，傳給玩家。
4. 玩家登入後，到右上角 👤 →「🔑 修改密碼」，把臨時密碼改成自己的。
   （舊的登入狀態會被登出，所以玩家一定要用新密碼重新登入。）


四、其他
--------
- 帳號不分大小寫（BOO1234 和 boo1234 是同一個）。
- 所有重設／查詢的動作會記在 gm/gm_log.txt（時間、動作、帳號），不會記密碼。
- 這個工具只能在你自己的電腦上用；不要把金鑰放到網頁裡。
